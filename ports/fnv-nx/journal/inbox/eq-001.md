* **decided**
  - CTOR1's PLACEMENT-NULLCHECK (61 functions) is a compiler-model class. MSVC 2008 null-checks every
    new-expression, even for an allocation function without throw() (measured with a tagged placement form at /O2
    and /Od). GCC -O2 emits no check, so the target code equals the explicit call's. Tried and reverted (no
    reduction).
  - EXTERN-RELOAD (STATIC1, 25): image-bound variables must have external linkage for the link-by-address. The
    reload after a call is the optimizer losing the internal-linkage assumption; the values are the same. Declared.
  - the std::abs code differences (3 locally): the exe's std::abs(float) at 0x00408840 is MSVC's out-of-line
    `(float)fabs((double)x)` (0x00408860 -> CRT fabs). The target inlines the standard abs: the same value for
    every input. CRT-INLINE.
