* **decided** - A record is labelled artifact or by-design only when the record itself shows that the difference
  is the harness's doing, or is allowed by C++/the ABI for every input. A value pattern or a static fact about the
  native object is not enough. That is what V1 refuted four times (C1-C3, U1-U2, A1-A4); each counterexample was a
  real native bug that produced the rule's own record.
* **did** - Two independent auditors built a real-bug counterexample for every artifact and by-design cause that
  causes.py assigns. The rules follow them (cdb9b9a, a55beb7, ae972b0):
  - **To triage** (no record evidence separates harness from bug):
    - ctor-this, canned-this, native-wild-private;
    - literal-arg, literal-store;
    - oracle-native-address, oracle-private-address;
    - vcall-garbage.
  - **To triage, owner S13** (the difference is by design or the harness's doing, but runner.compare stops at it,
    so the rest of the function is never compared):
    - deleting-dtor-ret, deleting-dtor-flags (48 of 95 deleting destructors had no other verdict);
    - byvalue-arg-dtor;
    - vcall-stub-alias.
  - **Tightened:**
    - x87-precision and nan-bits:
      - both values must be normal and of one sign;
      - a NaN must be a machine-generated NaN;
      - every difference must lie inside the window, with no store made by one machine only;
      - the int-parameter 256-ulp rule is gone.
    - stub-normalized: only arm64emu's exact rewrite.
    - literal-ret: a returned named-stub address goes to native-stub-data.
    - no-native-entry: native-undefined unless another object defines the function.
    - libc-variant: a table of the exe's _CI* entries.
    - oracle-callee-store: call records only.
    - oracle-callee-unloaded: no other unit-local path to the evidence call.
    - oracle-trap: exactly exc:3.
  - **Back to the general cause:** vptr-store (to vptr-differs: a class-chain check needs the exe's RTTI) and the
    causes.py ilp32-pointer rule (to oracle-fault).
  - **Retired:** new-null. Since difffuzz-12 the allocators return heap blocks, so a canned 0 is a valid input.
  - **report.py:** no longer turns image-data vs native-image arguments into literal-arg before causes.refine, which
    shadowed native-address.
  - V1 C1-C3, U1-U3, A1-A4 pass. Self-test: 0 failures, with the audit counterexamples as cases.
