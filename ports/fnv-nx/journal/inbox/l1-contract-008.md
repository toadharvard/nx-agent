# L1 CONTRACT 008: загрузчик модулей, строгий линк, очистка от заглушек (2026-11-11)

Ветка claude/fnv-l1-contract. Числа измерены гейтами и тестами на этой голове.

## Сделано
- **Заглушки (приоритет 1).** `loader/`, `contract/`: удалён старый дизайн — trap-переходники, адаптеры deldtor,
  эвристический сканер кодовых указателей, fixups, пробы по порогу, разрешающий связыватель импортов, необязательные
  хуки: 18 файлов, 4 968 строк. `link/`: строгий линк, без PROVIDE и разрешающих опций. nostub (R1/R3/R4/R6) на
  contract+link+loader: 48 → 0 (R1 2→0, R3 43→0, R4 3→0). Текстовые правила линта отозваны владельцем.
- **Загрузчик модулей по правилу Windows** (`contract/modules.py`, `loader/src/modules.c`): тотальные статические
  базы для всех 9 несистемных PE32 каталога игры и redist (0x01410000…0x022d0000, после образа exe, по имени, 64 КиБ);
  статическое замыкание exe — 4 модуля (d3dx9_38, binkw32, libvorbis, libvorbisfile), 5 по LoadLibrary. Отображение,
  собственные релокации (57 759 применено на 4 модулях), экспорты из отображённого образа (имя, ординал, форвардеры),
  индексы TLS, защита секций, DllMain в порядке загрузчика, thread attach/detach, process detach,
  `fnvnx_module_load`. Слоты exe: 280 из 280 (240 ключей, 40 модулей). Слоты 4 статических модулей: 496, без
  поставщика 0. modcheck 111/111, startcheck 90/90. Сквозной прогон в эмуляторе с реальными файлами (тестовый
  `fnvnx_lift_enter`): exe + 4 модуля отображены, защита = таблицам секций, вход 0x00ecc4db.
- **Стадия ld с реальным тулчейном** (fnvnx-a64, newlib): множество неопределённых считается по таблицам символов ELF
  до строгого линка (замыкание по архивам библиотек), слабая неопределённая ссылка — красная; слова заголовка crt0
  пишет стадия; гейты `abs`, `pcrel`, `disp` структурные (disp доказывает хэш-поиск для каждого ключа по
  `fnvl_phf_params`). Синтетика 96 809 входов + реальные библиотеки: 97 168 имён, 0 неопределённых (с тестовой
  фикстурой хоста), RELR 406, текст 0x7e581b8, линкер 0,7 с / 229 МБ, запуск в эмуляторе при базе загрузки ≠ базе линка.
- **Пробный шард L3a (1/64, старая вселенная):** красный как ожидалось — 3 056 неопределённых: 2 182 тела других
  шардов, 831 имя платформы из rt.a, 28 `fnvl_msvcrt_*`, 9 из гостевого рантайма, 12 слабых.
- **hostapi.h:** VM_PROTECT=8, DISPLAY_DOCKED=9, ACCESS_FAULT_HANDLER=10 (FnvnxFaultFrame 816 байт), ≥16 сокеты L5.
- **Ключи импортов** под bridge 7f90015: 941 ключ; modules.tsv/exports: fnv-nx-build `l1-contract/mp4` bdc9ca9.
- Запрос L3b (3 `xchg` в CRT): операнд — константа 0x0127073C по внутриблочному распространению, выровнен; закрыто.
