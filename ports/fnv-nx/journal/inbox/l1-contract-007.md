# L1 CONTRACT 007: A7 на синтетике, A8 и A9 готовы (2026-11-11)

Ветка claude/fnv-l1-contract. Цель: первый полностью lifted ELF от точки входа exe.

- **A9 ключи импортов** (`contract/iat.py --keys-out/--c-out`, `loader/src/importkey.c`): одна таблица для загрузчика,
  переходников L3a и GetProcAddress L5. bridge.tsv a9fad987: 440 строк, 436 ключей, 4 data; слоты exe 240 из 280,
  расхождений 0; 40 слотов модулей красные. keys.tsv: fnv-nx-build `l1-contract/mp4` 2d685bc.
- **A8 старт загрузчика** (`loader/src/start.c`, S1..S8): SHA-256, отображение как в Windows (все секции, заголовки,
  дыры без доступа), строгие импорты (слот без поставщика = отказ старта со списком, значения-заглушки нет), TLS,
  защита секций PE (никогда не исполняемо для хоста), блок потока (стек+страж, TEB, вектор TLS), вход через
  `fnvnx_lift_enter`. startcheck: 78 проверок, 0 отказов (синтетический PE и реальный exe: 7 секций, SizeOfImage

  интерфейсом L3a (реальные phf.py и rt.a), 96 809 входов, `.text.fnvl` 132 МБ: неопределённых 0, disp 96 817 из
  96 817, pcrel 0 из 193 634, линкер 0,5 с / 108 МБ. При 175 МБ: 3 028 veneer, 1,4 с. Красные случаи ловятся (3 из 3).
- Вердикт дерева: pure 25/25, selftests 11/11.

## Согласовано с лидами
- L3a: ключи строго по keys.tsv; `fnvnx_lift_enter` пишет сентинел сам; `fnvnx_lift_imports_init` до первой гостевой
  команды; вселенная по R3 98 258+ (ждём `l3a-lift/facts`); статические базы модулей по modules.tsv.
- L4: ELF32 DF_1_PIE из PT_LOAD, база ≥ 0x05000000 вне запретных диапазонов; hostapi v3 + ext_call PLATFORM fn 8
  (защита страниц); слова заголовка crt0 пишет стадия ld; артефакты в `l1-contract/elf/<commit12>`.
- L5: тулчейн fnvnx-a64 + newlib; `platform/build_guest.sh` → libfnvnx-platform.a; data-импорты только через
  ELF-символ; CreateThread через `fnvnx_thread_block_create`.
- Оркестратор: загрузчик полный по правилу Windows (модули, DllMain до точки входа); первый измерительный ELF только
  с exe, 40 слотов красные, поведения-заглушки у них нет.

## В работе

- Линк реальным тулчейном (библиотеки newlib, заголовок crt0, гейт `abs`, pcrel по членам архивов).

## Записанные классы (не чинятся сейчас)
- Модули: отображение PE замыкания импортов, релокации, DllMain, индексы TLS > 0 (вектор TLS сейчас 1 слот).
- Таблица диспетчера не несёт параметров хэша: гейт disp проверяет слоты, но не то, что rt.a собран с теми же K1/K2.
- Переполнение стека → EXCEPTION_STACK_OVERFLOW (страж есть, доставка — рантайм SEH L3).
- TEB: заполнены +0, +4, +8, +0x18, +0x2c; PEB нет (во вселенной смещения fs только 0/0x18/0x2c — допущение L3a).
- Старые `codeptr.c`, `trap.c`, `deldtor.c` и API fixups ещё в дереве; в новый линк не входят, удаление — отдельная задача.
- Гейты L1 для вердикта слияния «не хуже базы» (запрос L4): одна команда + входы — после A7/A8.
