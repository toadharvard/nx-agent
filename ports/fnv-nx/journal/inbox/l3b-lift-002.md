### Решения
- Гейт forms — одна копия: lift/proof/formgate.py, владелец L3b; tools/gate_forms.py L3a удаляет. Контракт L1: вселенная = shapes.tsv пака (liftgen пишет ключи функцией proof/shape.py:shape_key), сертификаты = external l3b-lift/certs; оба как commit + tree_sha256; пины sha256 уйдут. Переделка чтения входов — один раз, после ключа GATE_CACHE от L1 (его w6).
- proof/ и test/ — пакеты Python (`from proof import …`, `from test import instest`): так импорты разрешает правило проекта в puregate. Shell-скрипты Sail и ферм перенесены в ports/fnv-nx/farm/ (sail_setup.sh, sail_build.sh, farm_shapeprove.sh); sail_build.sh после переноса проверен: IR sha256 55f87ab6…84f4, smoke ok.
- Узлы DSL нумеруются при создании (вместо id()); хэши форм не изменились: Form.sha() равен до/после для всех 26 500 кодировок, forms.json гейта побайтно тот же.

### Формы (C1): состояние
- Сертифицировано 0 / 26 500 (гейт красный). DSL строит форму для 19 481.
- Замер символьного доказателя на 340 кодировках: 327 доказано, 12 таймаутов (mov m,r 89; mov m,imm C7; imul 0F AF / 69; div F7), 1 расхождение: `bt m32,r32` при отрицательном смещении бита. По тексту модели (bit.sail, x86_bt_0f_a3) номер бита берётся как mod(abs(offset), 8) — похоже на дефект модели, не DSL; НЕ проверено на железе, воркер проверяет и правит ту сторону, которая неверна. Среднее 11,5 с на кодировку ⇒ порядка 60 ч CPU на 19 481, на фермы шардами.

### Не в порядке / открыто
- Допущение в memclass (не доказано, записано в докстринге): каждый вызываемый (прямой, косвенный, импорт) возвращает esp по RETN и сохраняет ebp. Замыкание по графу прямых вызовов, которое это требовало бы, упорядочивает 62 % обращений (38 450 входов «отравлены»), поэтому оно только измеряется. Правила, закрывающего класс без этой цены, у меня нет.
- Узкая загрузка в классе plain: компилятор может сузить `M64(a)>>32` до `ldr w,[x,#4]` (смещение меньше ширины доступа свёрнуто в 64-битный режим). Меняет адрес только если исходный доступ пересекает 2^32; так было и до R9. Допущение: гость не делает доступов, пересекающих 2^32. Не закрыто правилом.
- dsl_emit_test: 9 534 кодировки эмитированы, 8 634 компилируются (900 не компилируются — было и до сегодняшних правок); переключатель FNVL_EMIT=dsl и рукописные эмиттеры живы. Открытые решения эмиттера из ноты 001 не закрыты.
- FNVL_MEMCLASS как env и -DFNVL_FLAGS_IO / -DFNVL_TRACE — режимы; не убраны.
- Гейт C (rcp/rsqrt: сертификат исчерпывающего сравнения 2^32 на эталонном CPU + запрет FRECPE/FRSQRTE в объектах; float→int только по правилу) — в работе, результата нет.
- Отложено до первого кадра (слово владельца): немаскированные FP-исключения, мёртвые байты модулей, verify_r9.
