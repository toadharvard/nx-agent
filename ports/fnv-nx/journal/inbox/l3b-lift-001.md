### Решения лида (правила)
- Единица сертификата — кодировка (байты с символьными imm/disp), доказывается каждая; 1–2 образца на ключ формы — выборка, отменено. exe (вселенная 96 809, старая): 4 234 753 команды, 13 404 кодировки (цел. 8 437, SIMD 3 724, x87 1 243), 613 ключей. DSL строит форму для 8 401 / 8 437 целочисленных. По новому счёту доказано 0.
- C эмитируется из DSL (одна запись семантики); рукописные эмиттеры удаляются после переключения.
- xchg/lock с памятью: адрес — константа по внутриблочному распространению ⇒ выравнивание статически (L1: 3 места из 3, 0x0127073C); место без константы = ошибка сборки.
- FIP/FDP x87 ведутся в состоянии (1–2 записи на команду, +3,9 % кода x87), FOP из байтов кода.
