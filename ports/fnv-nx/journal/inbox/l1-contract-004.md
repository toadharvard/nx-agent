## J-XXXX L1 CONTRACT: «шейдеры транслируются только вне консоли» — статическое доказательство не проходит

Статус: результат для оркестратора и L6. Только чтение exe (exefacts v8, сертификат N1); кода не менял.

Вопрос (а): каждый байткод-аргумент CreateVertexShader/CreatePixelShader происходит из shaderpackage*.sdp.
Вопрос (б): D3DXCompileShader*/D3DXAssembleShader* недостижимы по графу вызовов либо получают только файлы, которых нет в поставке.

| Факт | Число |
|---|---:|
| импортов D3DX в exe | 25, у каждого один переходник `jmp [IAT]`, адрес ни одного не взят |
| функций, достижимых от точки входа, указателей кода в данных и живых vftable | 79 711 из 87 509 |
| D3DXCompileShader: прямых вызывающих, все достижимы | 3 |
| D3DXCompileShaderFromFileA / AssembleShader / AssembleShaderFromFileA: вызывающих, достижимы | 1 / 1 / 1 |
| D3DXCreateBuffer: вызывающий достижим | нет (vftable NiD3DGPUProgramCache никем из достижимых не ставится) |
| мест косвенного вызова со смещением слота 91 / 106 (верхняя граница: смещение, а не тип получателя) | 27 в 19 функциях / 24 в 14 |

(б), первая ветвь — недостижимость: НЕ доказывается. Все четыре импорта компиляции достижимы:
- D3DXCompileShader вызывают два загрузчика шейдеров игры (вершинный и пиксельный, по 23-24 вызывающих — функции инициализации
  каждого класса шейдеров, слоты живых vftable) и NiD3DShaderProgramCreatorHLSL;
- три остальных вызывают методы NiD3DShaderProgramCreatorHLSL/Asm, чьи vftable ставят достижимые конструкторы.

(б), вторая ветвь, и (а): доказуемо только условно. В обоих загрузчиках игры (N1 выполнен, порядок по коду exe):
1. имя ищется в загруженном пакете; запись найдена → байткод пакета идёт в Create*Shader;
2. запись не найдена → читается файл кэша `cache:\…vso|pso` либо открывается исходник HLSL; вызов D3DXCompileShader доминируется
   проверками «файл открыт»; результат компиляции идёт в Create*Shader.
То есть источников байткода три: пакет, файл кэша, компилятор. Утверждение (а) в безусловном виде неверно.

Условия, при которых трансляция вне консоли была бы полной:
- P1: каждый запрашиваемый шейдер есть в выбранном пакете (множество имён строится в 24 функциях инициализации форматированием
  в цикле — это вычисление, а не константы; перечислить его можно только исполнением либо абстрактной интерпретацией);
- P2: на носителе нет файлов кэша и исходников HLSL (свойство файлов игрока, включая моды, а не exe);
- P3: Gamebryo-путь NiD3DShaderProgramCreator* не получает файлов (.nsf/.hlsl/.asm) — то же свойство носителя.
P2 и P3 не следуют из exe; P1 не установлен. По приказу владельца это не правило класса.

Вывод: правило «только вне консоли» не доказано. Закрывающее правило — транслятор доступен в рантайме для любого байткода,
пришедшего в Create*Shader, а D3DXCompile*/Assemble* реализованы по контракту (R10); трансляция пакетов заранее остаётся
оптимизацией (кэш по хэшу байткода), не условием корректности.
