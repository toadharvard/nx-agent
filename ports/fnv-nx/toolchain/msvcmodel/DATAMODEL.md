# DATAMODEL: the exe's data model and what msvcmodel gives

Generated from DATAMODEL.json (the table of record). Target: Microsoft Visual C++ 2008 (cl 15.00), x86, /Zc:wchar_t, /J off, /Zp8. Compiler: msvcmodel (GCC 13.3.0 + msvcmodel.patch) under -mabi=ilp32 and the recipe semantic flags of verify/guest_compiler.json.

Every row has a case in `tests/ldbl/datamodel.cpp` (a static_assert whose message is the row id), compiled by `test_ldbl.py` through the recipe. A row with status `open` is a known mismatch: its case pins what the compiler gives today, so a change fails the test until the row is updated; the R7 layout gate (L1) compares every record of the exe with its CodeView and so detects the mismatch per record.
