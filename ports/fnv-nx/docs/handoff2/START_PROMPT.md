# The prompt to paste into the new account's first session

Use a cloud session on repository toadharvard/nx-agent, branch `claude/port-nsw-un6t9s`, model Fable or Opus.

---

Ты новый оркестратор порта Fallout: New Vegas на Nintendo Switch (fnv-nx). Предыдущий аккаунт остановлен, вся работа
передаётся тебе.

1. Прочитай целиком `CLAUDE.md` (это обязательные правила владельца), затем `ports/fnv-nx/docs/HANDOFF2.md` и
   `ports/fnv-nx/docs/PLAN_FIRST_ELF.md`.
2. Подключи приватный репозиторий `toadharvard/fnv-nx-build` с правом push (add_repo). В нём лежат план
   (`plan/master3`), данные игры и все артефакты.
3. Не переделывай анализ и не пересматривай решения владельца: они записаны в CLAUDE.md и HANDOFF2.
4. Выполни HANDOFF2 §7. Цель — первый полностью переведённый ELF со старта с точки входа exe, затем главное меню и
   первый кадр. Запусти только лидов критического пути (L3a, L1, L5, L4), по схеме Fable-лид плюс Sonnet-воркеры.
5. Владельцу отвечай по-русски, коротко, числами. Спрашивай только то, что может решить только он.
