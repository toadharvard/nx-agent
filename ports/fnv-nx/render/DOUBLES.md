# Test doubles census (render and tests/l6)

Commit: base 24f18cdb (claude/fnv-l6-render-w2) on branch claude/fnv-l6-render-w5; the census commit is the one that adds this file.

Rule (CLAUDE.md, no doubles in tests): per test binary, (symbols the test defines) ∩ (symbols the product roots define) = ∅. Boundary (GL library, deko3d, libnx, kernel) does not count.

## Method (mechanical, no allow-list)

- Product set A: `nm -g --defined-only` (aarch64-linux-gnu-nm) of the 69 objects of the render/d3d9 root built by `recipe.py build --root ports/fnv-nx/render/d3d9` (green; 1420 defined global symbols; ffp_prog.cpp not built, see MARKERS.md). Only admitted product root with a recipe.
- Product set B (not an admitted root, no recipe yet): host-compiled `nm` of render/backend/nx/dk_*.c, nxgpu4_check.c, render/gl4/gl4_*.c, render/shaders/src/*. Reported in its own column; not part of the rule's roots until admitted.
- Test side: per test driver, its own sources = every .c/.cpp/.cc under the test's directory, plus every source basename its driver .py names that exists outside the product dirs (render/d3d9/{dev,front,ffp,gen}, render/backend, gl4_*.c, shaders/src). Each is compiled with host gcc/g++ `-c` (`-m32`, ILP32 like the tests; 64-bit retry for libnx headers) and `nm -g --defined-only` taken. W/V/u weak symbols excluded; `main` excluded.
- Match: mangled name, or demangled name without the parameter list (ILP32 aarch64 vs host -m32 mangling differ). Where several tests share a file (e.g. tests/l6/copy/t_a.cpp used by devlife, draw, m1, pvw, tex), each test counts it.
- Host compile for `nm` only; this is a census, not a build.

## Totals (over all 40 test drivers)

- Tests: **40** (fully measured 20; partly measured 9; no native sources of their own 9; none measured 2).
- Against root render/d3d9: tests with a collision **17**; doubling files **14**; distinct symbols **30**; summed over tests **173**.
- Against product set B (backend/GL4/shaders, not yet a root): tests with a collision 0; files 0; distinct symbols 0; summed 0.
- Earlier partial census 06097801 (36 tests, 26 files, 88 symbols, 326 summed, 8 not measured) used logging wrappers over test runs; this one is static over all sources, so the numbers are not comparable one to one.
