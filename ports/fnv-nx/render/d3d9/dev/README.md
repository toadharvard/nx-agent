# render/d3d9/dev: object model + device state of our D3D9 (D1+D2)
Generated, not checked in: `gen/gen_impl.py OUT` -> `d9impl.gen.h` (class `Nx<Iface> : I<Iface>`, every spec method declared with `override`), `d9impl_methods.txt`, `d9impl_unk.gen.cpp`;
`dev/state_model.py OUT` -> `state.gen.h/.cpp`. Test: `python3 -I tests/l6/dev/test_dev.py` (g++ -m32; TEST builds link with `-Wl,--unresolved-symbols=ignore-all`, the gate's missing methods stay unresolved and are never called).
Gate G-METHOD = spec methods whose symbol is defined in the product objects (`nm`); a generated forwarder whose core method is missing does not count. Missing = the stream's progress metric.
## Files
`obj.h/.cpp` NxObj (IUnknown, bind refs, private data, priority); `state_model.py` the model; `state_gen.py` its engine; `state_rt.h/.cpp` device core, blocks, sparse sets;
`state_ext.cpp` hand-written state methods (lights, palettes, FVF, RT/DS, software VP, Create/Begin/EndStateBlock); `d9impl_hooks.h` base-class hooks (`NX_BASES_<Class>`).
## Object model (sources: Wine d3d9 tests device.c test_refcount/test_private_data/test_resource_priority, written against Windows; MS IUnknown / IDirect3DResource9 pages)
R1 Create* objects: public 1; while public > 0 one public reference on the device. R2 device holds IDirect3D9 (count 2 after CreateDevice). R3 implicit surfaces / chain: public 0, owned (never freed by count),
device held only while public > 0, no forwarding, GetContainer = swap chain / device. R4 level / face: AddRef/Release/count are the container's, device untouched. R5 bind references (stages, streams, RT/DS, blocks):
internal, invisible; Release to 0 while bound keeps the object, last unbind destroys; a bound level binds its container. R6 Release at 0 stays 0. R7 QI: the spec's `base` chain (Ex -> base ok, base -> Ex no), null + E_NOINTERFACE else.
Private data: IUNKNOWN size == 4, failed Set keeps the old entry, AddRef new before releasing old, Get(null data) reports size, too small = D3DERR_MOREDATA, per object. Priority: managed non-surface only, Set returns the old value.
## State model (`state_model.py`)
Table lines `NAME default blocks group` (render states, sampler types, stage types) and `FAMILIES` (name, element type, count, shape, default, blocks, group, setter/getter). Slots = one per settable unit; `mask[ALL/PIXEL/VERTEX]`
and defaults are computed by the compiler from the enum names. Shapes (kv, kv2, objat, obj0, stream, freq, val0, mat, vecat, range) generate Set/Get/Multiply bodies; all D3DERR_INVALIDCALL rules are in the shapes.
Rules: stage 0-7; sampler 0-15, D3DDMAPSAMPLER, VERTEXTEXTURESAMPLER0-3; stream/clip/RT index bounds; constants start+count within 256 VS / 224 PS F, 16 I, 16 B; null pointers; light type 1-3; texture pool not SCRATCH/SYSTEMMEM; only our objects.
**R-ignore**: a number naming no render/sampler/stage state: Set = D3D_OK and ignored (not stored, not captured), Get = D3D_OK, 0 (MS silent; Wine returns D3D_OK for every state; the release runtime does not validate values).
Recording (Begin/End): Set* of block members go to the block only, Get* read the device; non-members (RT, DS, palettes, software VP) apply at once. Blocks: ALL = everything but RT/DS/palette entries/software VP/clip status; PIXEL, VERTEX per MS pages.
Dirty groups: `NX_G_*` bits in `NxDeviceCore::dirty` (set by every device-visible write and by Apply). Cursor, gamma ramp, dialog-box mode are presentation state of the swap chain / device (Present/Reset module), not in NxDeviceState and in no block (MS lists none).
## Disagreements found (model = first named source)
1 ZENABLE: MS ZENABLE page TRUE iff auto depth stencil, MS pixel table FALSE, Wine always TRUE, nx_d3d9_default_rs FALSE -> model follows the creation parameter. 2 DEBUGMONITORTOKEN: MS D3DDMT_ENABLE (0), Wine 0xbaadcafe, nx_d3d9 0xDEADCAFE (the ONLY default where nx_d3d9_default_rs differs; test asserts exactly this).
3 DMAPOFFSET: MS sampler page 0, MS vertex-state page 256, Wine/nx 0 -> 0. 4 TEXCOORDINDEX: MS pixel table 0, MS stage page and Wine = stage index -> stage index. 5 POINTSIZE_MAX: MS table 1.0, Wine = caps value -> 1.0.
6 Block lists, MS vs Wine: pixel: MS adds AMBIENT/DIFFUSE/EMISSIVE/SPECULARMATERIALSOURCE, LOCALVIEWER, SPECULARENABLE, CCW_STENCILFUNC (Wine omits it: its list has the other three CCW ops, likely a Wine bug);
vertex: Wine adds FOGENABLE, NORMALIZENORMALS, SHADEMODE, SPECULARENABLE and has no stream dividers (MS does). Neither MS list names FOGENABLE / NORMALIZENORMALS: model takes Wine (vertex). SHADEMODE, SPECULARENABLE: MS (pixel).

Material default all-zero (MS silent, Wine zero-init); SetFVF(0) = D3D_OK no change (Wine); GetFVF = FVF of the bound declaration (Wine); NULL out pointers = INVALIDCALL (Windows would fault); GetPrivateData(null size) and SetPrivateData(null data) INVALIDCALL;

## Draw path (D5a: `draw_*.cpp`, test `tests/l6/draw/test_draw.py`)
Files: `draw_api` (the four Draw* methods of both device classes: validation = Wine 9.0 d3d9 device.c + the Windows rows of d3d9/tests/device.c test_draw_primitive, rules D1-D6 in its header), `draw_exec` (one draw: program pair -> layout -> textures / samplers -> buffer
mirrors -> pass -> `nxs_room` -> flush -> draw op), `draw_prim` (vertex-count formulas / NxPrim / instance count / D3DDECLTYPE as total switches), `draw_prog` (backend shader ids per (shader, variant, link set L) via `NXGPU_FN_SHADER_CREATE_D3D` of
`backend/nxgpu4_shader.h`, cached on the shader object, destroyed with it), `draw_layout` (NxVtxLayout4: unbound input = constant (0,0,0,0) stream, last element wins, instancing), `draw_ids` (process-global LRU tables of layout / state ids),
`draw_state` (passes with the NULL-format rules, render-state words, viewport / scissor / blend constant / depth bias, BindState), `draw_const` (UBO 0 / 1 / 2 byte-exact per `render/shaders/include/fnvnx_dk_layout.h`), `draw_tex` (sampler ids, texture
handles, sRGB view = image id + 1), `draw_bind` (vertex / index mirrors with the hazard rule, UP data through the segment payload, a block of its own above 128 KiB). `draw_ffp.h` declares the two functions of the fixed-function module (D5b), defined by `ffp_*.cpp` (rules F1 / F2 in `ffp_dev.h`, P1-P4 in `ffp_prog.cpp`, V1 / V2 / S1 / S2 in `ffp_sets.cpp`; programs embedded by `ffp/gen_glsl.py`, test `tests/l6/ffpdev`).
The one global stream keeps what it has bound (`g_nxb`): everything is emitted again when the pass epoch or the device changed, otherwise only what differs. Not carried to the backend (no field in the layout contract / ABI): user clip plane EQUATIONS (the enable
mask is in the state word) and point size / scale of programmable vertex shaders, a depth surface larger than the colour targets (backend pass rule), flat-shading variants of translated programs.

## Allocation failure (tests/l6/oom)
Memory is a RESULT, never a trap: `nxd3d_alloc` / `nxd3d_gpu_alloc` return NULL when the platform has none (the guest's address window is reserved whole, so this is an ordinary state). No product object references a terminating routine (`abort`, `__assert_func`, `__cxa_pure_virtual`, ..., `brk`), gate T of tests/l6/oom.
Rules. **A1** the allocators are `warn_unused_result`, `malloc`-attributed without `returns_nonnull`; objects are made by `nx_make<T>()` / `nx_make_plain<T>()` (obj.h), `new T` of a layer class is a deprecation diagnostic (the gates build with -Werror), so every allocation site is a call the compiler can enumerate.
**A2** every result is null-tested before its next use or returned upward (allocscan.py: clang AST, exact; gcc -fanalyzer as a second reader). **A3** an operation that fails leaves nothing behind and the device state is as before it: pieces are made in an order in which no later step can fail, a half-made object goes back through its own destructor
(`nx_destroy` / `release`), sets grow transactionally (`NxSparse::reserve` first, then commit: StateBlock::Apply). **A4** backend memory is allocated where an object is MADE, never where an operation runs (glue_stream.h E1-E4): creating the first image / query / buffer mirror reserves the stream ring, a DEFAULT image reserves the read-back staging for its largest sub-resource,
descriptors live in the ring's tail, payloads are split into ops of at most half a segment. Operations of existing objects therefore cannot fail for memory; a violation of that invariant is counted (`nxs_error`, `nxs_errors()`), never silent.
Result table (Wine 9.0 d3d9; the function that returns it): container object of CreateTexture / CreateCubeTexture / CreateVolumeTexture / CreateVertexBuffer / CreateIndexBuffer = D3DERR_OUTOFVIDEOMEMORY (device.c `d3d9_device_Create*`: calloc failure); their storage (buffer memory, CPU copies, conversion buffers) = E_OUTOFMEMORY
(wined3d buffer.c `wined3d_buffer_init`, texture.c `wined3d_texture_init` / `texture_resource_sub_resource_map`); level / face objects = E_OUTOFMEMORY (device.c `d3d9_surface_create`, `device_parent_texture_sub_resource_created`); the backend refusing an image or a query / mirror = D3DERR_OUTOFVIDEOMEMORY (wined3d resource.c "Out of adapter memory");
CreateRenderTarget / CreateDepthStencilSurface / CreateOffscreenPlainSurface = E_OUTOFMEMORY (device.c `d3d9_device_create_surface`); CreateStateBlock / BeginStateBlock / CreateVertexShader / CreatePixelShader / CreateQuery = E_OUTOFMEMORY (device.c, wined3d stateblock.c `wined3d_stateblock_create`);
CreateVertexDeclaration: object E_OUTOFMEMORY, element copy D3DERR_OUTOFVIDEOMEMORY (d3d9 vertexdeclaration.c); SetLight / LightEnable = E_OUTOFMEMORY (wined3d stateblock.c `wined3d_stateblock_set_light`; palettes: same, Wine's is a stub); SetFVF = D3DERR_DRIVERINTERNALERROR (device.c `d3d9_device_SetFVF`);
SetPrivateData = E_OUTOFMEMORY; StateBlock::Apply = E_OUTOFMEMORY (all or nothing); GetDC of a GPU-only surface (its CPU copy) = E_OUTOFMEMORY (wined3d texture.c `wined3d_texture_get_dc`); Lock of a GPU-written image cannot fail for memory (A4: its staging was reserved when the image was made; Wine would return E_OUTOFMEMORY, surface.c `d3d9_surface_LockRect`); Direct3DCreate9 = NULL, Direct3DCreate9Ex = E_OUTOFMEMORY (object) / D3DERR_NOTAVAILABLE (init) (d3d9_main.c);
Clear / StretchRect / UpdateSurface / UpdateTexture / GetRenderTargetData: E_OUTOFMEMORY (a conversion buffer) or D3DERR_OUTOFVIDEOMEMORY (stream); PreLoad / GenerateMipSubLevels are void: a failed upload leaves the dirty regions and the next use retries and reports.
