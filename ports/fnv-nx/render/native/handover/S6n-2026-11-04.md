## D3D9 semantics as Nine implements them (to mirror in the translator)

### Depth and stencil

* **Depth:** write is forced off when ZFUNC is EQUAL or NEVER. `D3DCMP_NEVER_ZERO` is treated as NEVER.
* **Two-sided stencil:** the back face takes the `CCW_*` func/ops and shares the front masks. Ref and masks are
  dynamic (deko3d `dkCmdBufSetStencil`).
* **Depth bias:** D3D9 bias is in depth units, while GL and deko3d want multiples of r. Units = DEPTHBIAS x 2^24
  for D24 (Nine uses 1<<23 when the driver has no unscaled mode); slope = SLOPESCALEDEPTHBIAS.
* **Depth range** is [0,1] (half-z): deko3d `DkDeviceFlags_DepthZeroToOne | OriginUpperLeft`, GL
  `glClipControl(GL_UPPER_LEFT, GL_ZERO_TO_ONE)`.

### Blend

* Without SEPARATEALPHABLEND, alpha uses the RGB factors mapped through the alpha table.
* BOTHSRCALPHA and BOTHINVSRCALPHA are fixed up: dst becomes INVSRCALPHA or SRCALPHA respectively.
* BLENDFACTOR is the constant colour, converted from ARGB.
* COLORWRITEENABLE1-3 are per render target.

### Rasterizer

* **Cull:** gallium's front face is CW in y-down window space (`front_ccw=0`). D3DCULL_CW culls the front,
  D3DCULL_CCW culls the back.
* **Fill:** SOLID_ZERO counts as SOLID.
* **Flat shading** uses the first vertex as the provoking vertex.

### Samplers

* With MIPFILTER NONE, LOD bias and MAXMIPLEVEL are ignored. Otherwise min_lod = max(MAXMIPLEVEL - managed LOD, 0)
  and max_lod = 15.
* MIN/MAG filter is nearest only for POINT; everything else is linear. Anisotropy applies only when MIN or MAG is
  ANISOTROPIC.
* MIRRORONCE maps to MIRROR_CLAMP_TO_EDGE (`DkWrapMode_MirrorClampToEdge`, GL `GL_MIRROR_CLAMP_TO_EDGE`). Cube
  textures are always clamp-to-edge.
* Border colour is D3DCOLOR (ARGB) converted to RGBA floats. SRGBTEXTURE selects an sRGB view.

### sRGB write, fog, alpha test

* **sRGB write:** SRGBWRITEENABLE switches the framebuffer surface to its sRGB format, so blending happens in linear
  space. deko3d: an sRGB image view. GL: an sRGB texture view plus `GL_FRAMEBUFFER_SRGB`.
* **Fog** (ps < 3.0 only, in a PS epilogue):
  - linear: factor = sat((end - z) x 1/(end - start));
  - exp: 2^(-z*d*log2 e);
  - exp2: the same with (z*d)^2;
  - otherwise the vertex fog factor.

  The result blends toward FOGCOLOR.
* **Alpha test** compares against ALPHAREF/255. It stays a shader bit for now; deko3d also has a hardware alpha
  test (`DkColorState.alphaCompareOp` + `dkCmdBufSetAlphaRef`), a later N4 option.

### Formats

* A8R8G8B8 -> BGRA8_Unorm (GL `GL_BGRA` + `GL_UNSIGNED_INT_8_8_8_8_REV`); X8R8G8B8 -> BGRX8.
* R5G6B5 -> BGR565_Unorm; A1R5G5B5 -> BGR5A1; X1R5G5B5 -> BGR5.
* A4R4G4B4 -> RGBA4_Unorm with view swizzle B,G,R,A.
* L8 -> R8 as RRR1; A8 -> R8 as 000R; A8L8 -> RG8 as RRRG; V8U8 -> RG8_Snorm.
* DXT1 -> BC1 RGBA; DXT2/3 -> BC2; DXT4/5 -> BC3; ATI1/ATI2 -> BC4/BC5. Still to check in `basetexture9.c`:
  whether Nine swaps X/Y for ATI2.

## Next steps, in order

1. Build dekotools for the host, then `make lib/libdeko3d.a` with devkitA64.
2. Pure state translator `render/native/front/d3d9_state.{h,c}`, as C with an `extern "C"` API for V6n.
   - Input: `DWORD rs[210]`, `samp[16][14]`, scissor, viewport, clip planes.
   - Output: an `NxRenderState` of several u64 words:
     - blend: separate alpha and 4 render-target masks;
     - depth-stencil: two-sided ops, ref and masks;
     - raster: D3D cull, fill, bias flag, scissor, sRGB write, clip mask, point sprite.
   - Plus the dynamic values (blend constant, depth-bias floats, alpha ref, fog parameters) and a `shaderBits` word
     (alpha func, fog table/vertex mode); a 16-byte `NxSamplerState` per sampler.
   - Mirror the rules above, with one unit test per state.
3. Generalise the front:
   - carry `NxRenderState` in DefineState;
   - add ops for stencil ref, blend constant, depth bias and scissor;
   - shader creation takes `{stage, dksh, glsl}`;
   - texture handle = image | sampler << 20, the deko3d packing, for both backends.
4. GL 4.5 backend `render/native/gl/nxgl.c`:
   - EGL surfaceless context, functions loaded through `eglGetProcAddress`;
   - the same command stream and `Backend` interface, plus a readback API;
   - bindings: GL binding = stage x 16 + deko3d slot;
   - `glClipControl(GL_UPPER_LEFT, GL_ZERO_TO_ONE)`, first vertex as provoking vertex;
   - a cull scene test: on-screen CW must survive D3DCULL_CCW.
5. Shader build: GLSL -> DKSH (libuam or the CLI) and GLSL -> GL through the shim (version rewrite + bindings), in one
   package. Port the existing shaders and add a shared D3D9 epilogue include (alpha test, fog).
6. N0 scenes: textured, sorted, instanced quads, plus one conformance scene each for cull, blend, stencil, sampler
   and format.
   - Run them on the GL backend; golden PNGs go under `tests/`.
   - An ILP32 guest + a host module with nxgpu (new ext module id, `-ldeko3d`) into exefs.nsp, reading the same
     scenes back to SD to compare with the goldens.
7. RENDER_NATIVE.md: what N0 delivers, the backend split, how verification works, the trap list, and the C API for
   V6n.
