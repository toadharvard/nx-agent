# SM1-3 production table and handler coverage gate (schema v1)

Rule (A), translator totality, part 1.  Nothing here is a hand-written row: `sm_table.json` (generated by `sm_table.py` from the pinned MS docs and
Wine 9.0 `dlls/wined3d/shader_sm1.c`, one cited record per fact) is the only input; `gen_productions.py` is a stage of the total root
(`gen/productions.json`); `gate_productions.py` reads the translator's own dispatch mechanically and checks productions minus handled = empty.

## productions.json

```
{ "format": "fnvnx-sm-productions/1",
  "table_sha256": "<sha256 of gen/sm_table.json>",          // the one source
  "kinds": ["op", "dstreg", "dstmod", "writemask", "srcreg", "reladdr", "srcmod", "swizzle", "dcl", "sampler"],
  "productions": [ PRODUCTION, ... ] }          // sorted by id; ids unique
```

PRODUCTION = one element of the SM 1.x-3.0 bytecode grammar of one model.  A bytecode instruction is accepted iff every element it uses is a
production of its model (the grammar is factored per element; the validator checks the element-wise conjunction plus the per-opcode shape):

| field | meaning |
|---|---|
| `id` | `<model>:<kind>:<key>` (unique) |
| `model`, `stage` | `vs_1_1 .. ps_3_0`, `vs`/`ps` (the creatable models of sm_table.json `models`) |
| `kind` | one of `kinds` |
| `key` | the element, per kind (below) |
| `form` | the kind's attributes (below), copied from the table |
| `source` | the table record's own citation: `MS:<page>` and, where it widens or narrows MS, `wine-9.0:dlls/wined3d/shader_sm1.c:<table>:<line>`; the id of the `conflicts` / `undetermined` record if one decided it |
| `handler` | `{"class": <handler class>, "name": <symbol or case label>}` as found by the gate (absent in productions.json; the gate output adds it) |

Kinds (key / form):

- `op`: key = opcode id (`ps:mad`, `vs:sgn`, `vs:sgn/s3` for the 3-source-less form).  form = `{opnum, d, s[], mk, tex, ctrl, decl, flow}` of `opcodes[id]`.  One production per
  (model in `opcodes[id].models`, id).  Handler class `emit`: the translator's per-opcode emitter.
- `dstreg`: key = destination register type in `models[m].dst_regs`.  Handler class `regtype`.
- `dstmod`: key in `models[m].dstmods` (`sat`, `pp`, `centroid`).  Handler class `dstmod`.
- `writemask`: key = a write-mask form allowed by `writemask` for the model (`any` subset; `single` for the ops of the masking page; the fixed
  forms of vs outputs).  Handler class `writemask`.
- `srcreg`: key in `models[m].src_regs`.  Handler class `regtype`.
- `reladdr`: key = `<reg>[<a0|aL>]` for every entry of `models[m].regs[reg].rel` (relative addressing of that register file by that index).  Handler class `reladdr`.
- `srcmod`: key in `models[m].srcmods` (`neg`, `abs`, `absneg`, `bias`, ...).  Handler class `srcmod`.
- `swizzle`: key = a swizzle form in `swizzle_forms[models[m].swizzle]` (the model's swizzle class).  Handler class `swizzle`.
- `dcl`: key = `<usage>` of the table `usages` (vs input/ps input dcl_usage forms).  Handler class `dcl`.
- `sampler`: key = sampler type of the table `sampler_types` (`dcl_2d`, `dcl_cube`, `dcl_volume`).  Handler class `dcl`.

## Handler coverage gate (gate_productions.py)

The handler classes are read from the translator's own dispatch, never listed:

- `emit`: the `INSTRUCTION` / `INSTRUCTION_STATE` X-macro list of `mojoshader_internal.h` (the entry's position is its opcode token) joined with the
  `emit_<PROFILE>_<op>` definitions of the one profile the ABI requests (`mojoshader_profile_glsl.c`).  An op is handled iff its entry exists at
  its opcode value, its shader-type mask contains the stage, and its emitter is not the `RESERVED` emitter.
- `regtype`, `srcmod`, `dstmod`, `swizzle`, `reladdr`, `writemask`, `dcl`: the `case <ENUM>:` labels of the switch statements of the same profile
  that consume that element (`REG_TYPE_*`, `SRCMOD_*`, the dst modifier bit tests, the swizzle/writemask string builders), joined to the
  production keys through the enum values of the ABI headers (`d3d9types.h` token values), e.g. `neg` = `D3DSPSM_NEG` = `SRCMOD_NEGATE`.

Output `gen/productions_gate.json`:

```
{ "format": "fnvnx-sm-coverage/1", "table_sha256": ..., "productions": N, "handled": H,
  "unhandled": [ {"id": ..., "cause": CAUSE} ... ],
  "by_cause": {CAUSE: n}, "by_kind": {kind: {"productions": n, "handled": n}},
  "status": "green" | "red" }
```

CAUSE is one of: `no_entry` (the dispatch has no entry for the key), `reserved` (entry present with the RESERVED emitter), `stage_mask` (entry's
shader-type mask lacks the stage), `no_case` (a switch of the class has no label for the key), `unmapped_key` (the key has no enum value in the ABI
headers: a table/ABI gap).  green iff `unhandled` is empty: a production with no handler is a build error.
